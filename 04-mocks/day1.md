## Rubric (score 1–4 each)

| Dimension | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| Clarifying questions | Jumps into code | Asks 1 constraint late | Restates problem, constraints, examples before coding | Also names brute force vs target complexity up front |
| Correctness | Fails examples | Works on happy path only | Handles stated edges | Dry-ran + extra edges (empty, dupes, single element) |
| Complexity | Cannot state | States but wrong | Correct time/space after coding | Chooses the approach *because* of the complexity target |
| Code quality | Unreadable / Python traps | Works but messy | Clean `Solution` method, named vars | Interview-ready: dummy/pointers/maps used idiomatically |

Passing a FAANG screen is roughly **3+ on all four**. A 2 on correctness is a no-hire even if the rest is 4.
