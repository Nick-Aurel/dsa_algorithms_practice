# Day 3 mocks — 2 × 45 minutes

**Rules:** timer on, no notes, speak the whole time. Two full mocks. Then recode your 5 weakest problems from a blank file.

Suggested Mock A: LC 200 Number of Islands + LC 70 Climbing Stairs  
Suggested Mock B: LC 207 Course Schedule + LC 53 Maximum Subarray (or LC 39 Combination Sum)

## Rubric (score 1–4 each)

| Dimension | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| Clarifying questions | Jumps into code | Asks 1 constraint late | Restates problem, constraints, examples before coding | Also names brute force vs target complexity up front |
| Correctness | Fails examples | Works on happy path only | Handles stated edges | Dry-ran + extra edges (empty graph, 1x1 grid, k=0) |
| Complexity | Cannot state | States but wrong | Correct time/space after coding | Chooses the approach *because* of the complexity target |
| Code quality | Unreadable / Python traps | Works but messy | Clean `Solution` method, named vars | Interview-ready: visited, adj list, dp definition said out loud |

Passing a FAANG screen is roughly **3+ on all four**. A 2 on correctness is a no-hire even if the rest is 4.
